Política de Privacidade

Última atualização: 11 de novembro de 2026.

1. Quais dados coletamos

O CyberSeguro é um site informativo e não exige cadastro. Não coletamos nome, e-mail, telefone ou qualquer dado pessoal por formulários.

2. Armazenamento no seu navegador

O checklist "Como se Proteger" salva quais itens você marcou usando o localStorage do seu navegador. Essa informação fica somente no seu dispositivo e não é enviada a nenhum servidor. Você pode apagá-la com o botão "Limpar checklist" ou limpando os dados do site.

3. Serviços de terceiros

Para funcionar, o site carrega recursos de terceiros, que podem receber seu endereço IP e dados técnicos do navegador, conforme as políticas de cada um:

  • Google Fonts (fontes);
  • Cloudflare cdnjs (ícones Font Awesome);
  • Tailwind CSS (estilos via CDN);
  • Unsplash (imagens).

Os botões de compartilhamento apenas abrem a rede escolhida (WhatsApp, Facebook, X ou LinkedIn) em uma nova aba, e a partir daí valem as regras dessas plataformas.

4. Links externos

O site contém links para páginas de terceiros, como órgãos de denúncia e reportagens. Não controlamos o conteúdo nem as práticas de privacidade desses sites.

5. Seus direitos

Conforme a Lei Geral de Proteção de Dados (Lei nº 13.709/2018), você pode solicitar informações sobre o tratamento de seus dados pessoais. Como não coletamos dados pessoais diretamente, pedidos podem ser feitos pelo contato abaixo para esclarecimentos.
